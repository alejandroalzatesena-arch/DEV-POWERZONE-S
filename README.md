# PowerZone

Plataforma integral de gestion para gimnasios: usuarios, rutinas, membresias, pagos, acceso y analitica.

- **Backend:** Java 21 + Spring Boot 3.5 (monolito modular)
- **Frontend:** Angular 22
- **Servicio de IA:** Python + FastAPI
- **Base de datos:** PostgreSQL 16 + Flyway
- **Tiempo real:** WebSocket nativo
- **Documentacion de API:** OpenAPI 3 / Swagger UI

## Estado

Proyecto en construccion por sprints (Scrum). Ver `docs/SPRINT-MAPPING.md` para el alcance entregado.

## Estructura

```
backend/     API REST y logica de dominio
```
